# Customer Churn Prediction System

## Overview

This project is an end-to-end machine learning system for customer churn prediction using the KKBOX Churn Prediction dataset. The project covers the complete workflow from big data processing and feature engineering to machine learning model deployment and web application development.

The goal is to identify customers who are likely to cancel their subscriptions so that businesses can take proactive retention actions.

## Dataset

Dataset: KKBOX Churn Prediction Challenge

Files used:

- train.csv
- members_v3.csv
- transactions.csv
- user_logs.csv

The original dataset contains millions of customer records and user activity logs.

### Target Variable

text is_churn  0 = Retained Customer 1 = Churned Customer 

---

## Data Processing Pipeline

### 1. Data Storage

Raw datasets were uploaded to Amazon S3.

text Raw CSV Files         |         v Amazon S3 

### 2. Data Cleaning

PySpark running on Amazon EMR was used to clean the raw data.

Cleaning steps included:

- Removing invalid listening records
- Handling missing demographic information
- Replacing missing gender values
- Handling unrealistic age values
- Removing corrupted records

### 3. Feature Engineering

Customer-level features were generated by aggregating transaction and listening history.

#### Customer Features

- city
- bd
- registered_via

#### Transaction Features

- transaction_count
- avg_payment_plan_days
- avg_plan_list_price
- avg_actual_amount_paid
- auto_renew_count
- cancel_count

#### Listening Features

- log_days
- avg_num_25
- avg_num_50
- avg_num_75
- avg_num_985
- avg_num_100
- avg_num_unq
- avg_total_secs
- sum_total_secs

### 4. Feature Dataset

All features were joined into a single training dataset and stored as Parquet files.

text Raw Data     |     v Spark Aggregation     |     v Feature Dataset (final_features.parquet)

## Machine Learning Models

Several machine learning models were evaluated:

- Logistic Regression
- Random Forest
- Gradient Boosted Trees
- XGBoost
- LightGBM

LightGBM achieved the best overall performance.

### Final Model Performance

| Metric | Value |
|----------|----------|
| AUC | 0.9559 |
| Accuracy | 0.9514 |
| Precision | 0.7374 |
| Recall | 0.3722 |
| F1 Score | 0.4947 |

Threshold tuning was performed and a classification threshold of 0.30 was selected.

## Backend API
